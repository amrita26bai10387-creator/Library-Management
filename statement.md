# Project Statement

## Library Management System

### Project Overview

The **Library Management System** is a Python-based console application developed as an academic project for the **Python Essentials** course.

The purpose of this project is to provide a simple and systematic way to manage basic library operations such as maintaining book records, registering students, issuing and returning books, searching records, and viewing library statistics.

### Problem Statement

Managing books, students, and book circulation manually can become difficult and time-consuming. The system provides a simple software-based solution to organize these basic library activities through a menu-driven console interface.

### Objectives

The main objectives of the project are:

- To manage book records efficiently.
- To register and manage student records.
- To search books and students.
- To issue available books to registered students.
- To process book returns.
- To automatically calculate due dates.
- To calculate overdue fines.
- To provide basic library statistics.
- To demonstrate Python programming concepts through a practical application.

### Key Features

- Add, display, search, and remove books.
- Add, display, and search students.
- Issue books to students.
- Return issued books.
- Display currently issued books.
- Calculate a 14-day due date.
- Calculate overdue fines at ₹5 per overdue day.
- Validate user input and prevent duplicate records.
- Display basic library statistics.

### Technology Used

- **Programming Language:** Python 3.x
- **Libraries/Modules:** `os`, `datetime`
- **Data Structures:** Lists and Dictionaries
- **Interface:** Command-line / Console

### Data Storage

The current implementation stores books, students, and issued-book records in Python lists and dictionaries. The data is maintained in memory and is not stored permanently in a database.

### Project Scope

The system is intended for small-scale academic and demonstration purposes. It focuses on implementing the fundamental operations of a library using Python programming concepts.

### Limitations

The current version does not include:

- Database storage
- User authentication
- Graphical user interface
- Web or mobile interface
- Book reservation system
- Automated notifications
- Transaction history
- Cloud deployment

### Future Enhancements

The system can be further enhanced by adding:

- SQLite/MySQL database integration
- Login and authentication
- Admin and user roles
- GUI or web interface
- Book reservation and waiting-list functionality
- Transaction history
- Barcode/QR-code scanning
- Automated overdue notifications
- CSV/PDF report generation

### Declaration

This project has been developed for educational purposes to demonstrate the practical application of Python programming concepts. The implementation and features described in this statement correspond to the current version of the Library Management System.
