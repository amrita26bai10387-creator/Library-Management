# Library Management System

A simple console-based Library Management System developed using Python. 
The project is designed to manage books, students, book issuing and returning, 
and basic library statistics through a menu-driven interface.

## 📌 Project Overview

The Library Management System provides basic functionality required to manage 
a small library. It allows users to add, display, search, and remove books, 
register students, issue and return books, view currently issued books, and 
calculate basic library statistics.

The application uses Python lists and dictionaries for storing data in memory.

## ✨ Features

- Add new books
- Display all books
- Search books by:
  - Title
  - Author
  - Category
- Remove books
- Register students
- Display registered students
- Search students by ID or name
- Issue books to registered students
- Return issued books
- Display currently issued books
- Automatically calculate due dates
- Calculate overdue fines
- Display library statistics
- Input validation and error handling

## 📋 System Requirements

### Hardware
- Dual-core processor or better
- Minimum 2 GB RAM
- At least 100 MB free storage
- Keyboard and standard display

### Software
- Windows / Linux / macOS
- Python 3.x
- Command Prompt / Terminal

No external database is required because the application stores records in memory.
